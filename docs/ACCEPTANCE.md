## Проверка интерфейса

В браузере через SSH-туннель проверены:

- отображение сводки и таблиц;
- создание контрагента с двумя счетами;
- повторное открытие карточки и readonly ИНН;
- смена основного банковского счёта;
- создание проекта с выбором активных участников из справочника;
- сохранение календарных дат и ТЭП, включая дробное значение;
- повторное открытие проекта с сохранёнными данными;
- начальное значение фильтра «На проверке» и переключение на все статусы;
- ошибки незаполненной формы на русском языке рядом с полями;
- загрузка интерфейса после перезапуска сервисов.

Одноразовые записи, созданные для браузерной проверки, удалены после проверки. В рабочей БД оставлены демонстрационные **10 контрагентов, 13 банковских счетов, 5 проектов**. Тестовая БД остановлена. Рабочие данные находятся в постоянном томе Docker.

## Область подтверждения

Браузерная проверка выполнена на настольном размере окна. Адаптивные стили предусмотрены; отдельная проверка на физических мобильных устройствах, нагрузочное тестирование и проверка перезагрузки всей ОС не выполнялись. Проверен перезапуск сервисов и восстановление БД.

Авторизации и объединения контрагентов в этой версии нет. Приложение слушает `127.0.0.1:80` сервера и доступно через SSH-туннель. Известных воспроизводимых ошибок по выполненным сценариям на момент приёмки не осталось.

Подготовлен пример GitHub Actions `docs/github-actions.example.yml`. Автоматизация не активирована: существующий Personal Access Token не имеет права `workflow`, и GitHub отклонил первоначальную отправку файла `.github/workflows/ci.yml`. Приложение и тесты отправляются без активного workflow. Все перечисленные серверные проверки выполнены до отправки; облачный запуск CI не выполнялся.
