## Проверка интерфейса

В браузере через SSH-туннель проверены:

- отображение сводки и таблиц;
- создание контрагента с двумя счетами;
- повторное открытие карточки и readonly ИНН;
- смена основного банковского счёта;
- создание проекта с выбором активных участников из справочника;
- сохранение календарных дат и ТЭП, включая дробное значение;
- повторное открытие проекта с сохранёнными данными;
- начальное значение фильтра «На проверке» и переключение на все статусы;
- ошибки незаполненной формы на русском языке рядом с полями;
- загрузка интерфейса после перезапуска сервисов.

Одноразовые записи, созданные для браузерной проверки, удалены после проверки. В рабочей БД оставлены демонстрационные **10 контрагентов, 13 банковских счетов, 5 проектов**. Тестовая БД остановлена. Рабочие данные находятся в постоянном томе Docker.

## Область подтверждения

Браузерная проверка выполнена на настольном размере окна. Адаптивные стили предусмотрены; отдельная проверка на физических мобильных устройствах, нагрузочное тестирование и проверка перезагрузки всей ОС не выполнялись. Проверен перезапуск сервисов и восстановление БД.

Авторизации и объединения контрагентов в этой версии нет. Приложение слушает `127.0.0.1:80` сервера и доступно через SSH-туннель. Известных воспроизводимых ошибок по выполненным сценариям на момент приёмки не осталось.

Подготовлен пример GitHub Actions `docs/github-actions.example.yml`. Автоматизация не активирована: существующий Personal Access Token не имеет права `workflow`, и GitHub отклонил первоначальную отправку файла `.github/workflows/ci.yml`. Приложение и тесты отправляются без активного workflow. Все перечисленные серверные проверки выполнены до отправки; облачный запуск CI не выполнялся.

## Дополнение: заполнение по ИНН

Механизм добавлен и развёрнут 21 октября 2026 года. Источник внешних данных не выбран и выключен (`provider=none`, `enabled=false`) до уточнения API-доступа по приобретённым лицензиям Контур.Фокуса и Seldon. Доступ к реальным API не подтверждён, ключи не вводились, платные запросы не выполнялись.

- После изменения прошли 32 группы тестов: 13 для поиска по ИНН и 19 прежних интеграционных сценариев. Ошибок и пропусков нет.
- В отдельной тестовой БД и отдельном временном веб-сервисе проверены просмотр результата, подтверждение замены ручного ввода, заполнение, сохранение со счётом и повторное открытие карточки со снимком источника. Поставщик в этом стенде заменён контролируемыми тестовыми ответами, явно помеченными «ТЕСТ».
- Реальная рабочая форма проверена в состоянии без ключа: поиск недоступен с объяснением, поля ручного ввода доступны.
- Миграция `002_inn_enrichment.sql` применена. Контрольная сумма всех прежних полей контрагентов, счетов и проектов до и после обновления совпала.
- На сервере сохранены 10 контрагентов, 13 счетов, 5 проектов; тестовый стенд удалён, тестовая БД остановлена.
- До обновления сделана копия `backups/gardenmdm-20261021T143043Z.dump`, после миграции — `backups/gardenmdm-20261021T143912Z.dump`. Отдельная проверка восстановления новой копии не выполнялась; проверка восстановления первоначальной копии указана выше.
- Код рабочего образа не содержит тестового веб-сервера или тестовой подмены провайдера: fixture входит только в тестовый образ и защищён проверкой `NODE_ENV=test` / `PGDATABASE=mdm_test`.

Реализован адаптер DaData как резервный вариант, а не подключение Контур.Фокуса или Seldon. Для реального заполнения нужен выбранный API, подтверждённые условия доступа и проверка с его тестовым ключом. Документация: [INN-ENRICHMENT.md](INN-ENRICHMENT.md).
